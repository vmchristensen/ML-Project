# ML-Project

## Instructions for the code
The instructions to run the code are found in INSTRUCTIONS_CODE.txt, in the root directory.

## Organization of the repository
01_Data contains raw and preprocessed data for the train and test datasets, as well as the kaggle submission.csv.

02_Preprocess contains all the preprocess scripts.

03_Classifiers contains the code for all of the selected classifiers using the best set of hyperparameters and features.

04_Hyperparameter Tuning contains the code necessary to find the best hyperparameters for each classifier

05_Final model contains the scripts needed to train and save the model with the best performance and the script that uses said model to predict classes for the test dataset and generates the submission csv.
